질문이 흘러가는 순서

  1. 나 대화창에 질문
  2. 미니엉 앱 상태 질문이면 바로 답AI 0회
    "내 차례 뭐 있어?", "진행 상황" 같은 것
  3. Studio A 일반 질문을 실시간으로 답
    • 한도면 Studio B가 대신
    • 웹 조사는 Google 검색으로 출처를 붙여 답함. 한도가 끝나면 3시간 동안 바로 안내만
    • 질문과 업무가 섞이면 최대 5개로 나눠 처리
  4. 개발이 필요해 보이면 "업무로 접수" 링크 → 아래 업무 흐름으로

업무가 흘러가는 순서

승인 내가 누르는 곳자동 서버가 알아서
  1. 나 요청
    프로젝트를 고르고, 필요하면 @Codex·@Claude로 담당 지정
  2. Studio A 기획서 초안
    실제 코드를 보고 쓰고, 완료 기준을 필수·권장·선택으로 나눔
  3. 나 기획 승인
  4. 계획
    • 작은 일: 규칙으로 바로 배정
    • 큰 일: Claude PM이 작업으로 나눔(안 되면 Gemini가 대신)
  5. 서버 실행 승인 기록하고 바로 시작자동
    앞 작업이 있으면 끝난 뒤 시작
  6. Codex 개발 (주)
    Codex가 시작을 못 하면 Claude가 이어받음
  7. 결과 제출자동
    개발한 AI가 1회용 제출표로 앱에 직접 보냄
  8. 채점
    • 규칙 검사(AI 0회) → Gemini 100점 채점
    • 80점 미만이면 고칠 점을 적어 자동으로 다시 개발(최대 2번)
    • 결과마다 3중 평가(Gemini A·B + 동료 AI, 각 점수와 평균) · 선택: 두 AI 비교(다른 AI에게도 따로 맡겨 점수 비교)
  9. 나 올리기 승인
  10. 미노 PR 열기·검사
    승인된 변경 그대로 PR. 저장소에 CI가 없으면 대신 검사
  11. 나 배포 승인
    검사가 통과해야 누를 수 있음
  12. 서버 병합·배포자동
    release를 앞당기고(release가 없으면 병합이 곧 배포) 운영 버전이 바뀌었는지 확인

업무 카드의 기록을 열면 이 순서가 시간순으로 한 줄씩 남아 있다. 앱을 닫아 둬도 4~8번은 서버가 이어서 한다(실제 업무로 끝까지 시험은 아직).
