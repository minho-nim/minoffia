## 화면 작업에 필요한 취향

- 주 사용 기기는 아이폰 홈 화면 앱. 읽기 편하고 구분이 명확하게, 여백은 적게, 읽을 글은 줄이고 승인 이름은 우리말로. 버튼에 그림 아이콘은 넣지 않는다.
- 사무실 말풍선 모양·색 유지. ?는 내 결정, !는 막힘, […]는 작업 중.
- 기본 탭은 대화. 대화 탭 칩·화면은 소유자 요청 없이 바꾸지 않는다. 기본 대화창과 프로젝트 대화창 분리, 입력창은 아래, 휴대폰 Enter는 줄바꿈.
- 접기는 꽉 찬 삼각형(▶/▼). 업무 카드·프로젝트 칸 아래는 기본 접힘. 지도·입력은 가운데 팝업(✕·바깥 누르면 닫힘, 열린 동안 뒤 화면 잠금).
- 지도 그림은 floorplan처럼(점 무늬 바탕·흰 카드·설명 칸), 앱 색만, 빛·그라데이션 없이. 관계는 줄 보기 기본.
- 앱 아이콘은 미니엉 얼굴·#FFF4C2 바탕·흰 테두리 없음. 미니엉 코드 id는 mina.
