## 구현된 경로와 남은 확인

- Gemini 기획서 → Claude PM → 승인별 실행·결과·채점·PR·배포. 작은 일은 규칙으로 바로 배정하고 Claude PM 불가 시 Gemini 분배로 대체하는 코드가 있다. 운영 반영은 확인 필요.
- Codex는 Linear 이슈 위임·댓글 상태 읽기·웹훅 코드를 갖췄다. 기존 기록상 소유자 계정 연결·환경·LINEAR_API_KEY 설정은 완료. 실제 API 위임 시작·완료 응답과 결과 자동 등록은 미검증이며 완료 결과는 수동 등록한다.
- Claude 개발·자동 결과 제출·PR·서버 병합/배포의 전체 경로는 운영 로그로 다시 확인해야 한다. 세션 시작만으로 성공 처리하지 않는다.
- 여러 AI 결과를 하나로 통합하는 단계는 남은 과제. PR이 여러 개거나 CI가 실패할 때만 통합 AI를 쓰는 방향이며 단순 업무에는 추가 호출하지 않는다.
- 개발 결과 받기·채점은 서버에서 바로 한다(v0.5.90, 실제 결과로는 미확인). 계획 반영·채점 뒤 다시 개발 요청·배포 대기 재시도는 아직 앱이 열려 있어야 한다. Gemini 답은 25초 제한.
- 일일 상한·동시 실행 수는 임시값. 실제 사용량을 보고 소유자와 확정한다. 값은 코드·설정에서 확인한다.
- 미완료 운영 정리: pg_net 스키마 조치 적용 여부·Auth 유출 비밀번호 차단 확인. 시험 업무 삭제는 명시적 요청 때만.
- 개발일지는 MinLab 아카이브 프로젝트가 준비되면 이전. 회사 Windows PC 프로젝트는 소유자가 비공개 GitHub 저장소로 올린 뒤 연결한다.

## 화면 작업에 필요한 취향

- 주 사용 기기는 아이폰 홈 화면 앱. 읽기 편하고 구분이 명확하게, 여백은 적게, 승인 이름은 우리말로.
- 사무실 말풍선 모양·색 유지. ?는 내 결정, !는 막힘, […]는 작업 중. 내 차례 숫자는 있을 때만 표시. feat/bubble-v2·feat/bubble-readable 시안은 합치지 않는다.
- 기본 탭은 대화. 기본 대화창과 프로젝트 대화창 분리, 대화 삭제는 보고 있는 창만. 입력창은 아래에, 휴대폰 Enter는 줄바꿈. 일반 질문은 Gemini 스트리밍, GPT/업무 전환은 작은 링크.
- 업무 카드는 기본 접힘. 진행 단계는 접고 펼칠 수 있다. 기다림 그림은 업무 카드에 두고 사무실에는 넣지 않는다.
- 앱 아이콘은 미니엉 얼굴·#FFF4C2 바탕·흰 테두리 없음. 미니엉 코드 id는 mina.
