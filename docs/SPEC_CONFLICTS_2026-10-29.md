## 남은 확인
- 두 Gemini 키가 서로 다른 무료 프로젝트인지, 무료 한도(RPM·RPD) 숫자 — 소유자가 AI Studio에서 확인.
- `ask-gemini` 실제 호출(모델 이름이 맞는지) — 운영 배포 후 실측.
- GitHub 저장소 만들기 — 소유자가 토큰(`GITHUB_REPO_TOKEN`)을 넣은 뒤 운영에서 실측.
