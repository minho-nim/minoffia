## MinLab AI Office

v0.1 ~ v0.2.7

### 2D 도트 사무실과 승인 단계(A·E·B·C)를 갖춘 첫 공개

**작업 내용**

**작업 목적**
여러 AI(ChatGPT·Claude·Codex·Gemini·Grok)에게 일을 나눠 맡기고 진행 상황을 2D 도트 사무실로 보는 개인 AI 개발팀 사무실을 만듦. 사람이 승인해야 다음 단계로 넘어가는 흐름을 세움.

**주요 변경**
- React + Vite + TypeScript 앱과 Supabase(로그인·DB·서버 함수)로 첫 버전을 만들고, 캐릭터(미니엉·Studio A·Studio B 등)를 도트 그림으로 그림.
- 기획 승인(A)·실행 승인(E)·올리기 승인(B)·배포 승인(C) 단계를 DB 규칙과 앱 규칙으로 똑같이 막음.
- Claude PM이 기획서를 받아 작업을 나누고 담당을 정하는 계획을 만들게 하고, Codex는 지시서를 넘기는 방식으로 연결함.
- 요청 자료·결과 스크린샷 이미지 첨부(비공개 저장소), 링크 읽기(내부망 차단), 확인 질문·답변 기록을 추가함.
- 묻기·요청 입력창, 새 프로젝트 GitHub 저장소 만들기 버튼, 프로젝트 수정 기능을 추가함.
- 운영 배포는 release 브랜치만(Cloudflare Pages), 이 저장소는 시험 통과 시 PR·병합까지 자동으로 하도록 작업 규칙을 정함.

**작업 이유**
요청부터 결과 확인까지 여러 AI 창을 오가며 복사·붙여넣기 하던 일을 한곳에서 관리하고, 각 AI의 사용량을 아끼기 위해 시작함. 검증하지 않은 자동 실행을 성공으로 보이지 않게 승인 단계를 먼저 세움.

**작업 목적**

### 자동 채점·Gemini 개발·토큰 아끼기 규칙과 화면 증거

**작업 내용**

**작업 목적**
개발 결과를 사람이 보기 전에 AI가 먼저 채점해 고칠 점을 돌려보내고, 쉬운 일은 무료 Gemini가 개발하며, 모든 AI 지시서를 짧고 정확하게 만들어 토큰을 아낌.

**주요 변경**
- 조사는 Gemini + Google 검색으로 출처를 붙여 답함. 프로젝트별 대화창, 한 일 기록, 모든 프로젝트 기본 규칙을 추가함.
- 결과 점수 평가: 규칙 검사(토큰 0) → AI 채점(100점) → 80점 미만이면 고칠 점만 적어 자동 재개발(최대 2번). 서로 바꿔 채점(Claude 결과는 Gemini, 나머지는 Claude).
- 난이도 기반 배정(쉬움 Gemini·보통 Codex·어려움 Claude)과 Gemini 개발(GitHub Actions에서 무료 키 A·B로 개발·시험 후 작업 브랜치만 push)을 앱에 연결함.
- 견본은 Studio A·B가 한 장씩 만들고 소유자가 골라 승인함. PM이 계획을 멈추고 물으면 업무 카드에서 답하고 다시 보냄.
- Ponytail·Agent Skills·The Agency에서 고른 개발 습관(가장 작은 변경·보안 규칙·후한 점수 금지)과 저장소 지도를 지시서에 넣음. Gemini 개발이 데스크톱·휴대폰 화면을 찍어 결과에 붙이고, 코드 그래프(Graphify)로 호출부를 찾음. 개발 AI의 shortcut 주석을 "미뤄 둔 일"로 모음.
- 내 차례 바로 가기, 종 아이콘 알림, 첨부 사진 팝업, 확인 질문에 카드에서 바로 답하기 등 휴대폰 사용을 다듬음.

소유자가 "토큰 아껴야 돼", "그림은 내가 보고 고르기, 코딩 작업은 클로드가 채점"을 요청함. 견본 만들기가 안 된 원인이 PM 질문 미응답이라 답하는 길을 만듦. 외부 플러그인은 보안·적용 범위 때문에 깔지 않고 아이디어만 옮김(헤드룸은 실측 압축 0%라 제외).

### 계획 저장·Linear 추적 안정화와 '시작됨에 남는' 버그

**작업 목적**

**주요 변경**

- Linear 이슈 번호를 외부 호출 전에 예약해, 응답을 놓쳐도 성공으로 착각하지 않고 상태 조회로 되찾게 함. 지정한 팀이 없으면 첫 팀으로 보내지 않고 멈춤.
- Gemini 계획 만들기를 DB 예약으로 막아 여러 기기의 중복 호출을 없앰. 채점 실패는 30초~5분 간격으로 다시 시도.
- 서버가 시작한 작업(Gemini 개발·Codex)의 결과를 받아도 '시작됨'에 남던 버그를 고침(앱이 서버 확인 표시를 그대로 보내 DB 보호 규칙에 막히던 것).
