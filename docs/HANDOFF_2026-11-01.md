## 4. 소유자 취향·결정 (꼭 지킬 것)

- **쉬운 한국어**로 답한다. 영어 게이트 글자(A·E·P·B·C) 대신 우리말: 기획 승인 · 실행 승인 · 견본 승인 · 올리기 승인 · 배포 승인. 화면 진행 단계도 우리말(기획서·기획 승인·업무 계획·실행·개발·결과·올리기·배포).
- 핵심 기준: **"내가 보고 알아보기 편한 것", "구분이 명확한 것"**. 최종 목표는 사용자가 질문·승인·검토/수정 요청만 하는 것.
- **사무실 말풍선은 원래 모양 그대로**(`기획[?]` `조사[!]` `개발[…]`, 기존 색). 소유자가 개선안 3가지를 모두 보고 "원래거가 나음, 바꾸기 전 걸로"라고 결정. 시안 브랜치 `feat/bubble-v2`, `feat/bubble-readable`은 합치지 않음(다시 꺼내지 말 것).
- `?` = 내가 결정할 일(승인·답·시작), `!` = 막힘·멈춤 확인, `[…]` = AI가 일하는 중(기다림), 표시 없음 = 쉬는 중. 내 차례 목록과 같은 기준.
- 탭: **대화 · 업무 · 프로젝트 · 에이전트 · 팀 관리**(처음은 대화, 팀 관리는 v0.4.40 근무·휴가). 탭은 사무실 아래 고정, 스크롤하면 얇은 머리 + 절반 사무실 + 탭이 위에 붙는다. 여백은 적게.
- 업무 카드는 기본 접힘(한 줄), 펼치면 간단히, 맨 아래 "접기". 프로젝트는 카드로.
- **대화 탭은 기본이 일반 AI 질문 창**(Claude·ChatGPT처럼, 소유자 2026-11-01). 대화 탭 칩에는 "모든 프로젝트"가 없고, 프로젝트를 누르면 그 프로젝트 기준·다시 누르면 일반 대화. 업무 탭 칩("모든 프로젝트" 포함)과 따로 움직인다(v0.4.24).
- 입력창은 Claude 대화창처럼 크고 간단하게. 질문은 Gemini가 바로(스트리밍) 답하고, GPT·업무로 만들기는 작은 링크. 휴대폰 Enter는 줄바꿈.
- 입력창 미니엉 알림은 확인 질문·막힘만(승인 차례는 내 차례·말풍선·휴대폰 알림).
- 휴대폰 알림 켜져 있으면 빨간 "알림 끄기"만.
- 앱 아이콘: 미니엉 얼굴 + 파스텔 레몬 크림(#FFF4C2), 흰 테두리 없음.
- 배포는 소유자가 "배포"라고 할 때만(휴대폰이면 GitHub Actions 버튼을 Claude가 대신 실행). 이 저장소의 PR·병합은 시험 통과 시 Claude가 알아서. 운영 Supabase 변경은 지금까지 소유자 허락 아래 Claude가 했다.
- 유료 API 금지, 비밀값 채팅·코드 금지, Codex/Grok CLI 설치 금지, `minho-nim/MinLab` 건드리지 않기, 토큰 추출·브라우저 우회 금지.

  - Cloudflare Pages가 `ai/*` 브랜치를 빌드하려면 소유자가 Cloudflare 화면에서 미리보기 브랜치를 켜야 한다(Settings → Builds → Branch control → Preview branches에 `ai/*`). 미리보기 환경 변수(Supabase)를 비워 두면 미리보기는 로컬 데모 모드로 열린다(운영 DB 안 건드림, 권장).
  - **프로젝트에서 지켜야 할 것**(`project_rules`, 0027): Gemini 기획서 초안(`project_rules`), PM 계획 JSON 최상위 `project_rules`, 보조 개발 결과 `project_rules`로 AI가 적어 보내면 서버가 쌓는다(한 번 5개, 프로젝트당 40개). PM·보조 개발·기획서 초안·Codex 지시서에 함께 들어가고, 보조 개발은 저장소 CLAUDE.md의 같은 절도 맞춘다. 소유자는 프로젝트 탭에서 지우거나 직접 더하기만.
  - 함수 공통 코드 `projectRules.ts`는 5곳에 복사(같은지 시험이 확인): draft-spec·dispatch-claude·dispatch-claude-dev·submit-plan·submit-result.

## 7. 빠지기 쉬운 것 (추가)

- **소유자는 주로 휴대폰(아이폰, 홈 화면 앱)**으로 쓴다. PC가 필요한 일(Linear 설정, 회사 PC 프로젝트 올리기)은 "PC 앞에 있을 때"로 미뤄 둔 상태.
- **Gemini 답 속도 확인**: 소유자가 대화 탭에서 질문을 보내면 `ask-gemini` 로그의 `first_ms`(첫 글자까지 걸린 시간)·`total_ms`로 확인해 알려 주기로 함. 바꾸기 전 실측은 약 16초(서버 깨어나기 2초 + 답 13초).
- 탭의 주황 숫자 = 내 차례 수. **없으면 아무것도 안 보이고 있을 때 숫자만**(소유자 결정). 회색 열린 업무 수는 없앰.
- 데모 페이지의 `조사[!]`·`검토[?]` 같은 말풍선은 예시 데이터다(실제 앱과 무관).
- 배포 승인 뒤 main 시험 대기 중 자동 재시도는 **앱이 열려 있을 때만** 돈다(1분마다). 앱을 다시 열면 승인 24시간 안이고 배포 기록이 없을 때 한 번 더 시도.
- 남아 있는 시안·작업 브랜치(합치지 않음): `feat/bubble-v2`, `feat/bubble-readable`(말풍선 시안, 쓰지 않기로 함).
